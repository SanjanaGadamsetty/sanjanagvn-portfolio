## Alternative Sources

If the Simple Icons CDN links don't work, try these sources:

### DevIcon (Colored Icons)
Visit: https://devicon.dev/
- Search for your skill
- Download PNG or SVG

### Icons8 (Free Icons)
Visit: https://icons8.com/icons/set/programming
- Search for your skill
- Download free PNG (512x512)

### Flaticon (Free Icon Packs)
Visit: https://www.flaticon.com/
- Search for technology icons
- Download PNG (512x512)

## Bulk Download Method

Instead of right-clicking each link, you can:

1. Open each link in a new tab
2. The SVG will display
3. Right-click the SVG → Save Image As
4. Save with the correct filename

## Converting SVG to PNG

If you download SVG files, you can convert them to PNG:

**Online Tools:**
- https://cloudconvert.com/svg-to-png
- https://svgtopng.com/

**Or keep them as SVG:**
- SVG files work perfectly fine
- Just update the icon paths in `skills.ts` to use `.svg` instead of `.png`

## Quick Test

After downloading icons, verify they work:

```bash
npm run dev
```

Then visit: http://localhost:5173#skills

Missing or broken icons will automatically hide their icon area.
