# Sanjana Gadamsetty — Portfolio

A personal portfolio website showcasing my education, experience, skills, projects, achievements, certificates, and coding journey.

## Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

## Build

```bash
npm run build
```
